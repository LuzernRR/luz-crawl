开始使用

从完整 Skill 目录运行命令。需要 Node.js 24.5+、采集运行时 1.8.8、已加载本扩展的 Edge / Chrome。doctor 证明连接，实际原文与登录状态需另行验证。

node scripts/luz-crawl.mjs doctor
node scripts/luz-crawl.mjs search xhs "关键词" --read 1 --comments --download
node scripts/luz-crawl.mjs capture "https://example.com/article" --comments --download

每次搜索都打开真实网页。任务完成后立即关闭自己的工具页，保护用户原有标签；并行任务也分别关闭。需要登录/验证码时最多保留一页，其他任务保存并关闭。

node scripts/luz-crawl.mjs pending
node scripts/luz-crawl.mjs continue TASK_ID
node scripts/luz-crawl.mjs cancel TASK_ID

手动完成登录或验证后，在对话中告诉助手继续，或运行 continue。明确取消时才使用 cancel。

保存的数据与下载

post.account：名称、账号标识、主页。post.text/images/videos：目标正文、图片、视频/封面。post.engagement：赞评藏、分享、浏览量，保留原值和近似标记，隐藏数据为 null。comments：本次加载的评论/讨论、作者、正文、时间、点赞。

默认是工作目录 outputs/luz-crawl；已记住的用户路径优先。根目录只保留多个 NNN_原标题.html、一个参考链接.md、一个 raw 文件夹。原始快照、截图、评论、媒体与验证清单在 raw 内。

node scripts/luz-crawl.mjs download DIRECTORY
node scripts/luz-crawl.mjs verify DIRECTORY

DIRECTORY 用采集结果的 folder。图片与直接视频下载在页面关闭后执行；可选 yt-dlp 下载公开视频，不导出 Cookie。每图最多 25 MiB、每视频最多 250 MiB。链接可能过期、受登录/DRM 限制；失败会单独记录。视频简介、文件下载、字幕与完整转录不是同一个结果。

浏览器操作接口

JSON actions.json 可描述 read、scroll、screenshot、click、type，每次最多 20 步。点击/输入需要唯一可见 CSS 选择器及 --allow-write；密码输入交给用户。click 只触发一次 DOM 点击，后续 read 核验页面变化；可信指针手势尚未验收，不自动重复点击。点赞、关注、发送等必须已有用户对具体目标和内容的明确授权；当前仅预留通用入口，未验收各平台写入适配器。

[
  {"action":"read"},
  {"action":"scroll","direction":"down","amount":600},
  {"action":"screenshot"}
]

node scripts/luz-crawl.mjs browser "https://example.com" --file actions.json

记忆与有效网址

preferences 记住用户明确指定的保存格式、路径和偏好；sites 登记新网站；events 保存当前验证过的路线、关键词与失败；pending 保存人工待办。单次 --out 不改变长期默认。经验帮助选路线，每次仍重新搜索。

node scripts/luz-crawl.mjs remember --out "D:\Research\LuzCrawl" --format html
node scripts/luz-crawl.mjs experience --query "关键词" --platform xhs
node scripts/luz-crawl.mjs remember --site "https://example.com" --name example --template "https://example.com/search?q={query}"

遇到 404、拒绝或空白，先检查请求地址、落地地址、域名与内容 ID，从真实站内入口重进。可尝试同一内容的公开页面；不能访问的登录/验证码交给用户，不越过付费权限。错误页面不能记成成功经验。

排错与删除旧扩展

断连：核对加载目录是否直接有 manifest.json，确认本扩展已启用，重启 daemon，并用 --profile 选定连接。修改扩展文件后在扩展页点击重新加载。

旧扩展：在 edge://extensions 或 chrome://extensions 找到旧 OpenCLI / Browser Bridge，点击移除并确认，保留 LuzCrawl。先保存/停放旧任务；停用也能防止重复连接。

partial：检查滚动预算、未展开内容、下载失败及 limitations。连接成功、归档哈希通过、搜索有结果，都不能证明全站或全部评论已采集。

调试横幅：浏览器使用已加载扩展的名称；本扩展显示 LuzCrawl。协议字段、运行时包名和第三方法律声明保留上游标识。
