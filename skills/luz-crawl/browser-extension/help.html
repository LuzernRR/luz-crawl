LuzCrawl 使用说明

2.7.0 · 浏览器搜索 · HTML / 媒体 · 本地记忆
安装使用 / 下载保存目录可用网站接口 / 排错

1. 安装

从仓库安装 完整 Skill 到 ~/.codex/skills/luz-crawl/。需要 Node.js 24.5+，Edge / Chrome；从最终目录运行：

cd "$env:USERPROFILE\.codex\skills\luz-crawl"
npm install -g @jackwener/opencli@1.8.8
node scripts/luz-crawl.mjs install
opencli daemon restart
  1. 扩展页：开发者模式 → 加载解压缩的扩展 → browser-extension/（其中直接有 manifest.json）。停用旧桥接扩展。
  2. 运行 node scripts/luz-crawl.mjs doctor，确认 ready 和 bundled_loaded 均为 true。更新扩展后“重新加载”。
  3. Agent：完整 Skill 放入 ~/.codex/skills/luz-crawl/，从最终安装目录运行 install；新对话使用 $luz-crawl。

2. 使用 / 下载

node scripts/luz-crawl.mjs collect "浏览器自动化工具"
node scripts/luz-crawl.mjs collect "https://example.com/article"
node scripts/luz-crawl.mjs collect "人工智能" --platform all --read 1
node scripts/luz-crawl.mjs download "E:\Research\LuzCrawl\raw\001_原标题"

collect 默认按主题选择平台，逐站搜索、读取、下载并汇总一份 HTML。--platform all 遍历全部可用平台；--read 1..20 为每站读取数。补下载使用返回的 folder。

给 Agent 的提示词：

使用 $luz-crawl 调研“浏览器自动化工具”。先规划平台和关键词，再逐站打开浏览器搜索、读原文、下载图片与可访问视频。raw 保存原始数据，整理一份含文字、图片、视频、账号、指标和已加载评论的 HTML 到 E:\Research\LuzCrawl。遇验证让我手动完成，用完关闭工具页。
使用 $luz-crawl 抓取这条链接：粘贴 URL。保存到 E:\Research\LuzCrawl，并下载可访问媒体；分别报告正文、评论和下载结果。

登录 / 验证后继续：pending → continue TASK_ID → report COLLECTION_DIRECTORY 更新合集。明确取消用 cancel。正常完成关闭工具页，保留用户原有标签。

视频依赖与 Agent 搜索计划

安装 FFmpeg，并安装公开下载器：

python -m pip install "yt-dlp[default,curl-cffi]==2026.10.21"
ffmpeg -version

Agent 可保存 plan.json，为各平台指定关键词：

[{"platform":"github","query":"browser automation"},{"platform":"xhs","query":"浏览器自动化"}]
node scripts/luz-crawl.mjs collect "主题" --file plan.json

3. 保存目录

扩展弹窗：默认保存目录 → 输入绝对路径 → 保存，下一次命令 / Agent 采集生效。

node scripts/luz-crawl.mjs remember --out "E:\Research\LuzCrawl" --format html

临时目录：命令后加 --out "E:\Research\本次"。优先使用临时 --out，其次浏览器 / 命令最新保存的目录，未设置为 outputs/luz-crawl/。

保存目录/
├── 001_原标题.html
├── 002_原标题.html
├── 参考链接.md
└── raw/   # 评论、媒体、截图、快照、任务

已有来源不会静默覆盖；--resume 校验后续接。媒体在工具页关闭后下载；单图 25 MiB，单视频 250 MiB。个人记忆保存在 Skill 的 opencli/memory/，不进入发布包。

5. 接口 / 排错

浏览器动作
[
  { "action": "read" },
  { "action": "scroll", "direction": "down", "amount": 600 },
  { "action": "screenshot" }
]
node scripts/luz-crawl.mjs browser "https://example.com" --file actions.json
node scripts/luz-crawl.mjs schema
node scripts/luz-crawl.mjs policy

JSON 保存为 actions.json，命令另行运行。支持定位、表单、提交、条件等待、提取与截图，最多 20 步；写操作需明确授权和 --allow-write，用 expect 核验效果。结果未知时不重放；读取有限重试，429 后持久冷却。真实点赞 / 发送尚未验收，密码由用户手动输入。

常见问题

断连：检查扩展、旧副本、daemon、--profile；目录未同步先重载扩展。partial 查看 limitations；404、限流和传输错误不等于未登录。评论仅本次加载，隐藏数值为 null；视频下载不代表字幕 / 转录完整。

旧扩展移除：扩展管理页找到旧 OpenCLI / Browser Bridge → 移除；保留 LuzCrawl 和已停放任务。
