# 验收边界

构建、文件完整性和离线测试只证明分发产物具备相应条件，不能代替当前网站、账号登录或完整采集验收。

平台说明中的公开样本记录来自历史验证。网站可能更新，同一站点的页面、搜索、详情、统计与媒体需要分别检查；可扩展网站库也包含尚未验证的候选和失败记录。

每次实际采集均以浏览器取得的目标内容为准：搜索外壳不算正文，视频简介不算完整视频，当前加载的评论不算全部评论。遇到登录、验证、限流或预算耗尽，保留真实状态并按 Skill 规则接续或停止。

verify 验证本地文件与记录的 SHA-256 是否一致，不证明来源真实性、网站当前可用性或下载权限。完整字段要求见[证据规范](evidence.md)。
