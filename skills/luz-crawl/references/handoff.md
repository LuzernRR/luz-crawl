# Resuming Interrupted Research

Use this reference when continuing an interrupted Luz Crawl task.

1. Re-read the user's latest request and any corrections or constraints.
2. Inspect the current workspace, existing outputs, and saved run manifest before repeating work.
3. Keep the original objective and completed evidence; do not restart or duplicate verified collection.
4. If the topic, platform, or output scope changed, record the change and update the search plan.
5. Continue from the first incomplete stage and validate the final saved dossier and manifest.
6. Report what is complete, what remains, and any source or access limits.
